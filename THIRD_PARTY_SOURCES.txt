15. Security Domain public metadata and software lifecycle (v0.15)
    https://docs.yubico.com/hardware/yubikey/yk-tech-manual/yk5-apps-scp.html
    https://globalplatform.org/wp-content/uploads/2023/08/GPC_2.3_F_SCP11_v1.3.0.13_PublicRvw.pdf
    Public review, not final v1.4. Tables 4-1/4-2 interpret measured SCP11 i=9b06:
    a/b/c, transient OCE key, chains, S8, X509 and no legacy format; no BF20 for a/c.
    Table 7-13 provides unsupported BF20 6A81, a source model without physical
    rejection measurements. Public manual describes CPLC 42-byte raw format,
    per-domain random data and automatic reset upon explicit last-key deletion.
    Our CPLC uses 0000 software platform and own random bytes, preserving clear
    identity differences from the physical 4090 chipset prefix. These lifecycle
    behaviors are SDK-tested over socket/direct IFD, not hardware reset evidence.
    security-domain-reference-observation.json contains only allowlisted shared
    PC/SC reads: fixed SELECT, OpenPGP-only GET VERSION, Domain GET DATA 66/E0/9F7F.
    Only fixed public SELECT AID/OID and recognition bytes plus key/CPLC schema
    are retained. No PIN, handshake, PSO, crypto, activation, reset or write was
    sent; volatile app selection changed. Unique CPLC/key-reference payloads,
    reader name, certificates and public keys are not retained. No PDF is bundled.

16. Full documented SCP03 key-version range and INIT metadata (v0.16)
    https://docs.yubico.com/hardware/yubikey/yk-tech-manual/yk5-apps-scp.html
    https://globalplatform.org/wp-content/uploads/2014/07/GPC_2.3_D_SCP03_v1.1.2_PublicRelease.pdf
    https://globalplatform.org/specs-library/secure-channel-protocol-03-amendment-d-v1-2/
    Yubico Key Sets documents custom SCP03 versions 1..254, reserving factory255.
    The implementation previously limited every SCP variant to 1..127; SCP03
    now uses its documented independent range. GP SCP03 INIT UPDATE key info
    contains selected version/protocol/i; option60 now agrees with the previously
    measured public recognition. Card authentication cryptograms are independently
    recomputed with AES-CMAC; unmodified SDK verifies encrypted import KCV and
    secure messaging for every custom version. GP 1.1.2 predates S16; the current
    public profile uses random S8 and R-MAC/R-ENC. No copyrighted PDF is bundled.
    SCP11's separate seven-bit P1 profile remains 1..127 (public-review F §7.6.2.1),
    and its exact hardware reservations/status are still unmeasured. All fixtures
    use fresh own software keys over socket/direct IFD. No physical device is
    opened for this checkpoint; INIT/boundary responses and hardware lifecycle
    have not been captured or proved equivalent.
