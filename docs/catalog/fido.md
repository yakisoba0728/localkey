# FIDO catalog status (lk-fido)

One line per bullet of the `## FIDO` section of `reference/BEHAVIOR_CATALOG.md`, in order.
Test names are unit tests in `crates/lk-fido/src` (`tests::<module>::<name>` under
`src/tests/`, plus `credential::tests::`, `pin_protocol::tests::`, `request::tests::` and
`state::tests::`). Run them with `CARGO_BUILD_JOBS=2 cargo test -p lk-fido`. Tests marked
`--ignored` are long repeat tests (docs/DESIGN.md §11): `cargo test -p lk-fido -- --ignored`.
PIN tests drive the authenticator with an independent test-side platform
(`src/tests/platform.rs`) that implements PIN/UV auth protocols 1 and 2 again with lk-crypto.
